Khusus Admin

Koneksi Database 1 Google Sheet via Web App Apps Script

Pastikan berakhiran /exec (bukan /edit atau /dev).

💡 3 Langkah Mudah Mendapatkan Web App URL:

  1. Buka Spreadsheet → Ekstensi → Apps Script.
  2. Klik tombol biru Deploy (kanan atas) → New deployment.
  3. Pilih Web app → pastikan Who has access: Anyone (Siapa saja).
  4. Klik Deploy dan salin URL yang berakhiran /exec ke sini!
